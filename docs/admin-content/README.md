# Words for the admin site

Tidied copies of pages whose words live in the admin site, not in the code. Each has **the same words, in the same order**, as the live page on 28 September 2026, with only the markup changed: real headings, lists and links in place of ordinary lines. See [legal-pages.md](../legal-pages.md) for why, and how they were checked.

| File | Admin site content | Page |
|---|---|---|
| `privacy.html` | `privacy` | https://www.gravelmaster.co.uk/privacy |
| `term-conditions.html` | `term-conditions` | https://www.gravelmaster.co.uk/term-conditions |

To use one: have it read by whoever looks after the site's legal wording, then paste it into that content in the admin site, in the editor's HTML (source) view, replacing what's there, and check the page after saving. It looks right in the old design and the new one.

If the words in the admin site change before then, these copies are out of date: make the same change here, or tidy the new words the same way.
